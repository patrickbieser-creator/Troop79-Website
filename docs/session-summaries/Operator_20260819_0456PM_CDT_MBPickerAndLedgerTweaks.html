Merit badge "I did this" picker — v1.51.1

Patrick reported the picker showed only high-level requirements. Ledger Tweaks — a checked, not assumed, batch

Patrick handed over an 11-item list of ledger tweaks and discussion questions for the Troop Finances module. Every item was investigated against real code, schema, and production data before anything was built — two assumptions going in turned out wrong, both caught by Patrick looking closely at real data rather than trusting a first-pass analysis.

Investigated, Turned Out Fine

The SoFi "false alarm." Patrick flagged a large number of transactions appearing attributed to the retired SoFi account. Investigation traced the account itself as real and correctly closed (2026-04-23, sweep to checking, both legs correctly paired) — but surfaced a genuine, separate finding along the way: 36 of the 41 SoFi-coded rows look like misfiled checking-account event-fee payments (same shape as sibling rows for the identical camps that correctly went to checking). Patrick's original alarm was a UI filter artifact, not this — but the 36-row pattern is real and independent of it, and is now on the backlog pending his confirmation before any correction (money records, no unilateral fix).
