How it went

Patrick worked the resume list top-down — the Remove note, the host-adult sentence, the June 28 calendar fix, the MB Progress refactor, the news editor gaps — then asked for two sweeps: make yesterday’s Save behaviour universal, and find every date format on the site. Both became full standards rather than patches: an audit first (65 save controls; 21 date formats across ~95 sites), a plan file, shared pieces with tests, then area-by-area commits so nothing big landed at once. The date sweep was fanned out to three parallel agents by file partition and gated once.

Late in the day a 70-line partial implementation of Discard appeared uncommitted in the tree from an unknown second job. Rather than fight it, its hook was kept and the rest built around it. One lesson recorded: React 19 re-syncs defaultValue every render, so an uncontrolled form’s Discard must write saved values back by field name, not call form.reset().

What shipped

Save standard rolled out to every admin edit form — v1.88.0 → v1.88.6, Discard in v1.88.8

Shared _components/save-state: dirty gate (controlled and uncontrolled forms), “Save changes” / “Saved”, Saving… → Done, and now “Discard changes” that returns to the last saved state. Applied to Calendar, the Builder editors, roster dialogs, News/Media, every Lookups editor, scout/person records, meetings, finance, notes, the patrol board and the Library narrative. Create-once forms and one-click actions deliberately left alone. Rule and pieces documented in AGENTS.md; live demo on the styleguide.

One date display standard — v1.88.1, v1.88.7

lib/format-date, Central-pinned, with calendar-day and timestamp inputs handled explicitly. Fixed genuinely wrong days: the public sign-up deadline (and in the reminder email), Library completed dates, and print pages stamping tomorrow after 7 PM. Retired 36 raw ISO renders and four slash variants; “today” defaults in finance and roles now use Milwaukee’s today. An ESLint rule keeps it that way.

Roll Call: Current / Past tabs — v1.88.9

Current is today and later with today on top; Past is most recent first. The year filter only offers years the view has and lets go of a stale choice on switch.

Smaller items — v1.87.6 → v1.87.9

Remove explains it frees the seat but is not a ban; the Guests lede names the responsible adult; calendar entry 18 retitled “No Troop Meeting” in production; admin MB Progress adopts the Library’s tested fold; the news editor can backdate a post and credit a scout.
