What was accomplished

The Calendar is the single point of activity

Event Signups, the standalone builder and Event Management are retired into the Calendar. Every status pill opens the entry workbench; the list gained a Going column; Roster, assignment sets, Money and Snapshot now render inside the Signup tab so the entry's head and tabs never disappear. The workbench loads one tab at a time (tabs are URL state, guarded by a Discard-changes prompt) and the list's counts come from one SQL aggregate — the fix for "overloaded and getting much slower on prod".

One Entry editor

Details and Story consolidated on the news editor's shell — numbered sections in Jenna's order, the story's split pane full width, one Save. Description and the homepage card summary collapsed into one field (prod rows migrated). Tabs: Entry · Agenda · Signup · Roll Call.

One way back, in one place

PageTitle now requires back: "← Back to Parent" at depth 2, breadcrumbs at depth 3+, folding on phones. Lists remember their URL so back restores the tab/search/set; dirty forms prompt before leaving — automatically, through the save-state hooks. Swept across all 38 admin screens.

Standards that enforce themselves

Seven table/list patterns on one shared stylesheet, composed per screen (two waves, every Compact and Card screen migrated). The ? help badge (popover, click-only, central copy) with an on-screen-instructions ladder in AGENTS.md; the calendar lede migrated. A shared name search on every roster tab. Numbered form sections in the news editor. Each has a styleguide specimen; prototypes are linked from the styleguide chooser.

Signup confirmation emails

Spec first (five revisions as Patrick answered questions), then built in three parts: family receipt to every signed-up member (all parents cc'd when only scouts signed up), leader notification to up to five addresses or "use the family message", strict cross-list dedup, resend on edit and cancel, Reply-To the first leader, a send log with Resend on the roster, an open-ended template library under Lookups, and — the same day — full markdown with an email-safe renderer, a real-email preview, an editable Going: section and preview-as-a-real-household.

Supabase security sweep

A stray unprotected backup table (RLS'd, then dropped), ten Security Definer views made security_invoker, EXECUTE revoked from anon/authenticated on every function (service-role explicit), search_path pinned everywhere, an always-true ledger policy dropped. Applied locally first with the suite green, then prod; the advisor now reads 0 errors, 0 warnings. Production data synced to the local dev database.
