How it went

Patrick worked live, one ask at a time, each landing as its own release. It started small — give Leadership / Planning meetings a roll call — and the root cause turned out to be a heuristic (credit-or-activity) standing in for “tracks attendance”; the fix was a template gate. From there the asks compounded: tabs on the entry workbench, tabs on the Roll Call sheet, then the big one — fold Roll Call & Agendas into the Calendar entirely, one line per event, with letter pills instead of wordy badges. That was specced by question-and-answer first (eight questions, all answered), then built in one pass. Three follow-ups the same evening put the Roll Call sheet, the agenda editor and the signup builder inside their tabs rather than behind a button.

The night closed with the backlog’s oldest debt: a shared admin Button and FormPanel. The component, tests, Save/Discard adoption and styleguide were built by hand; the sweep across 38 stylesheets ran as three parallel agents, one per area, each returning a structured report. One agent caught a cross-folder regression another had introduced (a deleted class still imported by the roster); another found three finance buttons that had referenced never-defined classes since July. Every screen was then verified in the dev browser with a minted leader session, including an immediate-save round trip on a roll call checkbox (checked → count 1 → unchecked → 0, database left clean).

What shipped

Roll Call & Agendas is gone; the Calendar is the one list — v1.89.0, v1.90.0

tracksAttendance() gates by template (meetings and activities, never announcements), so PLC and committee meetings list. Every calendar row is one line: day-only date with weekday/time on hover, Event title with ellipsis, muted category, author as initials, 12-character location. The Status column is letter pills — Agenda (green published / yellow draft), Signup (green open / grey closed), Roll call taken (count on hover), and a red O only when an entry is off the calendar — each in its own column, each a link into its layer. Import CSV and the Actions menu retired; Attendance Report moved under Reports & Exports with Scouts / Adults tabs; Delete agenda sits at the top of the agenda editor; the old route redirects.

The entry workbench and Roll Call sheet on the tab pattern — v1.89.0, v1.89.1, v1.90.1

Details · Story · Agenda · Roll Call · Signup as pill tabs; panels stay mounted so drafts survive a tab switch; the Story tab shows a dot while dirty. The Roll Call sheet became Scouts / Leaders / Adults / Inactive tabs with present-count pills and cross-tab search hints. Then the tabs began hosting the editors themselves: the Roll Call checklist, the full agenda editor (embedded, with its own status / Publish / Delete strip), and the signup builder with its event-pages strip. Recorded on the styleguide as the “tabbed workbench” pattern for long multipart editors.
