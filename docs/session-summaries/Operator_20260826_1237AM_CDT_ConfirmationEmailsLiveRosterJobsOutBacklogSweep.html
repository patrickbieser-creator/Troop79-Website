What was accomplished

Confirmation emails, tested live and corrected

Patrick signed up for the Eagle Court of Honor on prod and read the receipt. Three findings, three fixes: the summary now speaks only to the blocks the signup offered (an attendance-only event no longer prints a Rides caption or "Amount due: $0.00"); the roster's Resend sent nothing because it looked the household up under the wrong key — the prod send log said so in one row; and the message editor stopped closing on its own (the dialog's scrollbar and drag-selects were being read as backdrop clicks — fixed for every admin dialog). The template picker's unstyled <select> was a one-line CSS miss.

The test suite stops mailing Patrick

Seven [test→…] relay emails per npm run test traced to a live Resend key in .env.local reaching the identity-auth tests, which never needed delivery. vitest.config.ts now strips the credentials; EMAIL_LIVE_TESTS=1 opts back in on purpose. A guard test keeps it that way.

Jobs leave the roster grid

The per-job tick columns and day bands are gone ("a mess on the rummage sale"), with the Print and Hide-jobs buttons. Job coverage now names everyone signed up under each job — open by default, click to fold — and the two add buttons ("+ Add a scout or adult", "+ Add a guest") sit together under "Someone missing?". Edit / Remove right-aligned.

Backlog sweep — six items in one release

Roster name search on both tabs; one PublicPageLink at six admin→public sites (Jenna's spec — including the news editor, which had no link at all; drafts say "Preview (unpublished)" instead of hiding); the troop's Facebook group and BeAScout pin published as sameAs; the calendar Story preview on newsprint; finance and news pagers on the shared button; the events grid and Lookups action columns composing the shared table patterns.
