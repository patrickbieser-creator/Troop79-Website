What Was Accomplished

Signup form: a mistyped email no longer sinks the whole signup (v1.118.5)

Reported by Patrick: an adult signing up for the Eagle Court of Honor on September 13 added a parent on the fly and got new row for relation "person_emails" violates check constraint "person_emails_email_shape". The email box was a plain text input; whatever was typed went straight to add_parent_to_household, whose people.primary_email trigger writes person_emails, whose shape check rejects anything without an @. The RPC runs in one transaction, so nothing was half-saved — but nothing was explained either.
  • Server-side shape check before any write — new lib/new-adults (parseNewAdults, newAdultEmailError) validates every on-the-fly adult in the action and redirects with a sentence naming the adult and the value: “414-555-0100” doesn’t look like an email address for Jodi K. Fix it, or leave the email blank and add it later from your profile.
  • Same guard on the profile page — addHouseholdMemberAction shares the RPC and had the same hole (its input was already type="email", so only a pasted value could reach it).
  • The signup input is now type="email" with inputMode="email", so the browser catches the typo first; the server check is the real gate.
  • Test-first: 7 tests in tests/new-adults.test.ts written and seen failing before the helper existed. Lint 0, typecheck clean, 1619 tests, build clean. Vercel deploy confirmed READY in Production.

Local Supabase moved to ports 44320–44329

Found the hard way: the first full-suite run failed in all 185 files with fetch failed, and the build died exporting /events. Local Supabase reported “running”, but supabase_kong_next-app had come back from a Docker restart with no host port binding at all — the same Windows ephemeral-range reservation problem Pen-Vision hit on September 5 (Hyper-V/WSL reserve moving blocks inside 49152–65535).
  • supabase/config.toml: API 44321, Postgres 44322, shadow 44320, pooler 44329, Studio 44323, Inbucket 44324, analytics 44327 — a 1:1 digit shift from 5432x. Pen-Vision keeps 44331–44339.
  • .env.local, the README (new “Ports” section with the why and the netsh diagnostic), and the 14 scripts’ URL fallbacks updated.
  • supabase stop + start preserved the data volume; the full suite is green on the new ports. Any next dev started before the move needs a restart.
