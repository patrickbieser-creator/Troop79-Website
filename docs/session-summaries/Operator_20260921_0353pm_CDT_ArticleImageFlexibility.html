What Was Accomplished

The bug report: “the rummage sale news article. The image is cropped.” The live page carried the flyer twice — as the hero (un-cropped since August) and as an inline body image that the renderer still forced into a 16:9.5 letterbox. Patrick asked for a plan before any code; Jenna reviewed the three asks; Patrick said “Go!”.

v1.129.0 — Body images show the whole picture; the hero can be hidden or removed

  • Body figures follow the hero’s rule — width fixed, height free, a plain <img> instead of next/image fill in a fixed-aspect box. No max-height guard, by decision. Verified on production: the flyer renders 760×826 for a 1247×1355 source, whole poster visible.
  • “Show hero image at top of article” — a new articles.show_hero column and editor checkbox (default on) with the hint “Still used as the card thumbnail and social preview image even when hidden here.” Plus a Remove button, parity with the calendar form.
  • Migration re-created the two select * views (articles_public, articles_archived) — Postgres freezes * at creation — restating security_invoker. Pushed DB-first, then code.
  • First tests the ArticleBody renderer has ever had.

v1.130.0 — A picture in a story can be a link

  • [![alt](src "caption")](href) — native markdown, no new token — used to break the page (<p><a><figure>, a hydration error). An a override now folds the href into the figure.
  • Three link kinds: the image’s own file (full size, new tab), a site path (same tab), anything else (new tab + noopener).
  • The caption is the link text — hover does not exist on the troop’s phones. No caption → “View full size ↗” / “Open link ↗” / “Open →” so the target is never invisible.

v1.131.0 — Insert Image form; images edit in place

  • Picking a photo opens an inline form under the toolbar (caption + Link to: None / Full-size / A web address) — the same pattern the Gallery Link and Video buttons use — replacing a bare window.prompt.
  • Images in the live preview get the Edit button galleries and videos have had since D-088; the remark pass annotates the outer link span, so an edit replaces the whole linked image and nothing around it. Builder and parser round-trip exactly.
  • ArticleBody’s component overrides are now built once per edit handler and cached — the live preview no longer remounts every image on every keystroke.
Quality gate on every release: lint 0 · typecheck clean · full suite · production build · browser-verified on localhost (test edits reverted, local DB untouched) and on production. qa-lead: SHIP on steps 1 and 3.
