What Was Accomplished

The outcome: the Menu Monster page now opens on a menu plan for everyone. Scouts sign in to save menus, plan day by day with a page per meal, shop from one merged list, and report what they paid, which keeps the troop price book current within a safe band. Leaders see every scout’s menu and review held prices.

Releases

  • v1.133.0 — scouts save menus: My menus, the Plan tab (pulldowns, one line of People / diet dialers, budget), the approved meal page, the merged Shopping list with a priced snapshot, the browser-draft offer, and a shared compact dialer that also reached event sign-up.
  • v1.134.0 — your version of a recipe: change an amount, swap, leave out or add an ingredient for one menu; merging two people now moves the merged-away person’s menus.
  • v1.135.0 — hub, leaders, prices: the Menu Monster page as the hub; leaders read every menu; “What you paid” with live verdicts; scout prices update the book within ±50% (per unit) of the last leader-set price, else held; admin Needs attention / Price changes with Apply, Dismiss and Revert.
  • v1.136.0 — stores: an editable store list in Lookups & Admin.
  • v1.137.0 — one planning flow: visitors and leaders plan on the same screens (kept on this computer), per-day recipe search, the Spent / Used / Leftover / Budget panel and a printable list; the old one-meal planner retired from the page.
Caught on the way: the audit log would have silently dropped every scout row (its area CHECK); menus linked to the ledger’s events lookup instead of the calendar; people-merge didn’t move menus; a ±50% band measured from the current price could ratchet — now anchored to the leader’s price.
