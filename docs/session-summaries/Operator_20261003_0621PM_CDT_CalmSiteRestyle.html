What Was Accomplished

The outcome: every page on the site now reads like Menu Monster — sentence-case labels, borderless white cards, no heavy rules, quiet buttons and text tabs — and a test fails if a new stylesheet brings the loud patterns back. News, articles and Home keep their newspaper look.

Releases

  • v1.144.0 — Menu Monster, one control per job: a day’s “+ Add a meal” offers only the meals it lacks; a meal’s search ends in “Browse all recipes…” (Food & Recipes for that meal). The day-level recipe popup is gone.
  • v1.145.0 R1 — shared public kit: forms, page headers, dividers, cards (+ a tight list recipe), notices, badges, tabs.
  • v1.146.0 R2 — buttons + event sign-up: sentence-case 36px buttons; price and choice questions become pulldowns.
  • v1.147.0 R3 — events, event detail, Profile, Member, Sign-in.
  • v1.148.0 R4 — Clipboard, merit badge tracker, advancement (print unchanged).
  • v1.149.0 R5 — admin shared kit: panels, sections, tables, titles, tabs “(n)”, notices, badges; labels sentence case and one size up.
  • v1.150.0 R6 — nine busiest admin screens.
  • v1.151.0 R7 — the long tail + styleguides; plan archived.
  • v1.152.0 — no “Suggest a Resource” band on Menu Monster pages.
Caught on the way: the bulk CSS script collapsed indentation in the R3 files (repaired in R4, no value changes, script fixed); it also stripped caps from the leader-code input (restored — data, not a label). Browser checks were thin: Chrome wouldn’t hold 375px and later stalled on screenshots, so R2–R7 rest on tests and builds.
