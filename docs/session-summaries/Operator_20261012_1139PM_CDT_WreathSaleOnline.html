What Was Accomplished

The outcome: troop-79.com/wreaths sells the 19 Rose items with photos. Each scout's link (e.g. /wreaths/ben-b) credits that scout, and the troop store can credit a scout optionally at checkout. Customers pay the treasurer by Venmo or PayPal, and leaders run it all at Admin › Finance › Wreath Sale.

Planning and design

Claude read the sale's Google Sheet: 19 items, prices, unit costs, and a 30% scout share of profit. It studied how other troops sell online and asked Patrick three rounds of questions. Brad's clickable prototype was approved. Claude split Rose's combined tree photo into two product images.

Reviews, then the build

Tech-lead, qa-lead and the troop specialist reviewed the plan before any code was written. Their work moved admin under Finance, keyed sellers on people, sent the scout share to the scout-account books, and added anti-spam and privacy controls. A builder agent wrote it test-first, and qa-lead reviewed the code twice. An Opus risk check cleared the production migration, which went in ahead of the code.

Live fixes

Patrick found that a capitalized link (Anjali-S) fell back to the store and showed another scout's name. Links now ignore case. He then asked for an optional "credit a scout" at checkout, a kinder message for a mistyped link, and an Empty the cart button. All of these shipped the same evening.
