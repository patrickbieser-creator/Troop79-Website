What Was Accomplished

The outcome: the wrong-item, wrong-amount Venmo order can be restructured to match what was paid, ledger and all. Any adult can now tick “What I can teach” on the Members page, and leaders see each change on admin home with Undo.

Wreath Edit order

  • One “Edit order” dialog replaces Reassign. It changes items, contact, the scout credited, delivery and, on hand-paid orders, the amount received and method.
  • Kept lines keep the price they sold at. A changed hand payment voids and rebooks the ledger row. A card-paid order's total is locked.
  • A shortfall needs “accept short”. An over-payment can count the extra as a gift. Emailing the customer is opt-in.
  • The open order now shows who is credited and how it's delivered.

Meeting board Phase 0a

  • Teaching skills and merit badge counselors are keyed to people, so a parent with no leader initials can teach or counsel. All 65 skill rows and 49 counselor rows carried over.
  • Summer Camp stays a counselor: it stands in for the council camp staff.
  • Any First Class scout or Junior Leader can be a Scout Instructor (it was Star and above).

Meeting board Phase 0b

  • New “What I can teach” page on the Members page for adults and Junior Leaders. Junior Leaders see only scout-teachable skills, with how many of each skill's requirements they've finished.
  • One logged database writer for the member page and Lookups. Lookups lists recent changes with Undo and Mark reviewed, and admin home shows how many are waiting. No email.
  • Browser-verified end to end locally. qa-lead passed it with warnings, and the material ones were fixed before production.
