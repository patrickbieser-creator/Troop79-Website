What Was Accomplished

The outcome: families see when each of their registrations runs out and how to renew; leaders can re-check the official roster any time; the newsletter list can be synced from People, greeting people by the names they go by.

The BSA roster

  • All 50 roster members matched People. Fixed in production: 16 YPT dates, two BSA IDs, a phone and a gender, Simon Pinix's name, and Maya's Eagle (board of review 9/10/2026).
  • New BSA Roster tool: upload the Roster Report to see every difference, then save each member's registration expiry, status, positions and auto-renew choice. It never rewrites names, addresses or ranks, and refuses an older roster.
  • The Members page Registration card is live, with a page listing the family's dates and a how-to-renew guide leaders edit in Pages.

Nicknames and test people

  • Everyone can have a nickname; the name shown everywhere is the nickname (or first name) plus last name, kept consistent by the database. Scoutbook keeps the formal first name.
  • Eleven nicknames set (Robbie, Becky, Adi, Ben ×2, Winnie, Nate, Dan, Chad, Mike ×2). Charlie Walters, Todd Manke and Alex Schaapveld are marked as test people.
  • A leader-name bug found while setting nicknames was fixed with a test the same hour.

EmailOctopus and clean-up

  • EmailOctopus Sync previews, then adds only the people you tick, updates names to match People, and records unsubscribes so nobody is ever re-added. Connected in Vercel; the first sync is Patrick's.
  • Wreath round 2 opened at noon Oct 20, when Summer called the round-1 order to Rose.
  • The old Google Sheets Roster Import and all of its tables are gone.
