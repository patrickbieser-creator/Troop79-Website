Session 66. Meeting Planner II is finished. The planner now opens with a full workflow: build the Sunday plan from suggestions or by hand, invite teachers and families from a dedicated tab, check Has/Needs and find scouts the plan leaves out, then run Meeting Live without any attendance being written automatically. What Was Accomplished

The outcome: a planner can now go from “what should we teach Sunday?” to “who’s teaching and who’s coming” in one place. Suggestions come from the advancement ledger. Teachers get one email with one page to answer, and that page also asks what else they’d enjoy teaching. The scouts the plan misses are listed. Attendance is recorded only when someone approves it. Every release passed the full test suite and a qa-lead review before shipping.

Meeting Planner II completed (P5)

  • Reminder emails, one per person, linking to the meeting page.
  • A merit badge night is now an ordinary meeting. The old mode switch, stations and Admin’s This Sunday tab are retired, and that tab lives on as “Who’s coming”.

Faster planner

  • Ticking a name no longer reloads the page twice. Requests per tick dropped from about 98 to 13, and the box flips the moment you click.
  • The site now runs in Cleveland, next to its database.

Build a Plan (new)

  • The plan is a list of offerings. Edit and remove each one, add a requirement, a focus set or a new mix, and use the persistent tool buttons.
  • Suggestions mode brings back the old Admin generator in full: Group Sessions, By Scout, Teaching, solo needs and campout items. Clicking a teaching chip asks for confirmation before it adds a requirement with that leader teaching.
  • The orphan check shows “N scouts have nothing on this plan”, with a reason for each scout.
  • Has/Needs moved from Admin to a planner tab. The Admin version retires once Patrick approves.

Invites

  • The full-screen Invite tab lists offerings, people and a review of who gets what. Its By person view lets one email cover all of an adult’s classes.
  • Teacher emails say which scouts each class helps. One “Choose what you’ll teach” page lets an adult answer everything and change their mind until 6 PM on the meeting day. The same page asks what else they’d enjoy teaching, now or later, and those answers appear in a “New talent” list for planners.
  • Emails to parents use scouts’ first names. When a scout has no email on file, a P.S. invites the parents to add one.

Meeting Live

  • Attendance is never written automatically. After the meeting, an “Update attendance?” checklist has to be approved.
  • A Live arrangement can be discarded. A “Needs attention” strip offers one-click fixes for drift between the plan and Live. Anjali’s Star 6 case is one example.
  • The model for making Live a schedule that stays in step with the plan was adopted. Its first phase, L0, is live.

Fixes found along the way

  • Proof approvals were signed with a full name and could carry the next day’s date. The production data is corrected.
  • Ledger edits are now in the audit log, and invite answers in the log now name who answered.
  • Saving a merit badge reset its requirements’ teaching minutes. It now keeps them, and the save is all-or-nothing.
  • The four tests that depended on local data were fixed for good.
