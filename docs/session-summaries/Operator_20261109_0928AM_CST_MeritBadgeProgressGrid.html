What Was Accomplished

The outcome: the Scout progress grid on every merit badge page matches the Concept A2 design. On Communication it reproduces the plan's acceptance table row for row. No schema change was needed: the choice rules were already in the catalog.

Merit badge Scout progress grid

  • Choice brackets ("any 1", "all", "9a, 9c + any 2 of 9b", "all of 5a or 5b") replace the "Req 1, Req 2" header row.
  • Boxes are done (green check), still to do (empty) or a dash when another option already covers them. A Progress column ("4 of 9" and a bar, or Earned) replaces the AWARD star.
  • Most-done scouts first; earned scouts below a line; a badge signed off with no detail gets one "All requirements complete" bar.
  • All four stat tiles stay; the "view as" scout's row is highlighted; on a phone the grid scrolls inside its card.
  • The rules come from the catalog tree (complete_rule nesting), so there was no new column and no 66-badge backfill.

Station checklist order

  • Climbing's station columns read 1a 1b 2 1c 3 and 6a 7a 6b… because sort_order only numbers siblings. They now follow the catalog tree.
