What Was Accomplished

The outcome: the local database is current again, and a startup crash in Git Bash no longer leaves it a day behind. The framework security fix is half done: a patch is installed locally but not tested or shipped, waiting on one choice.

Nightly backup

  • When Git Bash crashes before it starts, the step that copies production into the local database now tries again, up to three times, and notes it in the backup log. Any real failure in the copy still fails on the first try.
  • The backup and copy were run by hand; the local database matches production as of 10:46 this morning.
  • No root cause for the crash was found. It is not a second copy of the Git Bash runtime on the path, and it started before the Codex install.

Web framework security upgrade (scoped)

  • Two serious Next.js advisories affect us (a bypass of the admin gate and a denial of service through form actions); both are fixed by the 16.2.12 patch, now installed locally.
  • The audit still flags a third issue fixed only in 16.4, so the full fix means moving two minor versions up, which needs its own review.
  • The other flagged packages are development tools that never run on the live site.
