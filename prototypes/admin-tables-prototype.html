Admin tables — seven patterns

Throwaway prototype · real admin tokens · light theme. Resize to 375px to check the responsive notes under each specimen.

Which table do I use?

  1. If it goes on paper → PrintTable.
  2. Else if the user moves items between buckets → Board.
  3. Else if a row rolls up child rows the user only sometimes needs → ExpandableSummary.
  4. Else if each row is prose (a finding, a note) and cannot be scanned as columns → RecordList (sidebar variant for "recent N").
  5. Else if it is a matrix (people × slots, scouts × requirements) with 8+ narrow columns → Dense Grid.
  6. Else if rows carry money or per-row buttons → DataTable · Card.
  7. Else (a list you scan and click into) → DataTable · Compact. Default when unsure.
