What’s settled (2026-08-17)
  • Placement: under /advancement, both surfaces. No more IA toggle.
  • Archive: yes, permanently — archive.html is real, not optional.
  • Section 5 scope: leadership, award, and now service hours / camping nights / hiking miles — always included.
  • Per-entry dates: automatic, not a toggle — shown only when an entry’s earned date falls outside the report’s own range (a backfilled correction or old credit). Everything earned within the period stays date-free.
  • Correction path: confirmed as prototyped — unlock, edit, re-save; published_at stays, correctedAt is added.
  • First-run default: confirmed as prototyped — blank dates, Generate disabled until picked.
  • ★ EAGLE inline tag: confirmed and praised — no changes.
New this pass — scout-centric view

Every report now has a By Scout tab alongside By Category — same consolidated content, reorganized alphabetically by scout instead of by rank/badge, so a parent can find their kid and confirm everything got recorded without hunting across five sections. It reuses the exact same generated lines (no second query), and on the admin side, editing works identically in either view since both read and write the same underlying report. Each scout collapses to just their name and item count by default (an accordion — a plain button + hidden div, deliberately not <details>, see D-070) with Expand all/Collapse all controls and a filter box that auto-opens a single match. A shared link like report.html?view=scout&scout=Marcus+Whitfield opens straight to one scout, expanded and scrolled into view — everyone else stays collapsed.
