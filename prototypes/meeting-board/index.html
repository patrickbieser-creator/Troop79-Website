Prototypes

Meeting Requests & Teaching Offers

Plans/Meeting-Requests-And-Teaching-Offers.md, as clickable screens. One set of sample data (20 scouts, 8 adults) runs every screen, and it is shared: a pick made on a member page shows up on the admin board, the editor tray and the TV. Prototype “today” is Thursday, October 29, 2026. The first link in each walkthrough resets the data.
